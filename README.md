# 🛁 Тёплая Ванна

Расслабляющая мини-игра **для тех, кто лежит в ванной**. Лопай всплывающие
пузыри одним пальцем, грей воду и набирай очки. Никакого стресса и точных
движений — всё спроектировано под одну мокрую руку и телефон над водой.

## Как играть

- 👆 **Тапай по пузырям** — они лопаются и дают очки. Попадать легко: хитбокс
  большой и прощающий.
- 🔥 **Красные пузыри** подогревают воду.
- 🦆 **Резиновая уточка** — щедрый бонус (×10 очков).
- 💣 **Мыльная бомба** — цепной взрыв, лопает всё вокруг (и другие бомбы тоже!).
- 🌈 **Радужный пузырь** — сметает все пузыри на экране одной волной.
- ❄️ **Льдинка** — остужает воду (минус тепло). Появляется с 5-го уровня,
  к 12-му её становится много. Ловушка — лучше не лопать.
- 🌊 **Волны пузырей** — иногда всплывает целый рой, лови серию.
- 📈 **Уровни как в тетрисе** — чем больше очков, тем выше уровень: пузыри
  гуще и быстрее, вода стынет резвее. Вода меняет цвет от спокойного
  бирюзового до панического красного, а на высоких уровнях внизу
  разгорается **настоящий огонь** 🔥.
- 🧊 **Следи за теплом воды** — шкала сверху. Если вода остынет, заплыв
  заканчивается. Серии лопаний дают **комбо**, множитель очков и подбадривание.
- 🧘 **Дзен-режим** — вода не остывает. Просто лопай пузыри и расслабляйся,
  сколько хочешь.

## Особенности под «банный» сценарий

- **Управление одним пальцем**, крупные цели, увеличенный радиус попадания —
  удобно мокрыми руками.
- **Без таймеров-стрессов** и быстрых реакций. Темп спокойный.
- **Работает в браузере телефона**, ничего ставить не надо. Можно добавить на
  домашний экран (PWA-манифест прилагается).
- Мягкие звуки и лёгкая вибрация-отклик (если устройство поддерживает).

## Запуск

Это статичный сайт без сборки. Достаточно открыть `index.html`.

Локально удобнее через простой сервер (чтобы заработал манифест):

```bash
# любой из вариантов
python3 -m http.server 8080
# затем открыть http://localhost:8080 на телефоне в той же сети
```

Или просто открой `index.html` двойным кликом — игра запустится и так.

## Технологии

Чистый HTML + CSS + Canvas/JavaScript. Без зависимостей, без сборки.

| Файл            | Назначение                          |
| --------------- | ----------------------------------- |
| `index.html`    | Разметка, экраны меню/конца игры    |
| `style.css`     | Оформление, HUD, оверлеи            |
| `game.js`       | Игровая логика, рендер на canvas    |
| `manifest.json` | PWA — добавление на домашний экран  |
| `icon.svg`      | Иконка приложения                   |
